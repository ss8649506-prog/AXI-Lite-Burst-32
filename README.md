# AXI-Lite-Burst-32
AXI-LiteBurst-32 is an intermediate-level VLSI project developed as part of the HCLTech Career Shaper Programme 2025–26. The project focuses on designing and verifying a configurable AXI4-Lite Slave Interface using Verilog HDL. It includes RTL design modules, write and read data paths, testbenches, and simulation using Xilinx Vivado 2025.2.
