# AXI-LiteBurst-32: Configurable AXI4-Lite Slave Interface

## Project Overview

AXI-LiteBurst-32 is an intermediate-level VLSI project developed under the **HCLTech Career Shaper Programme 2025–26**.

The project focuses on designing and verifying a configurable AXI4-Lite Slave Interface using Verilog HDL. It includes separate RTL modules for write and read data paths, interface logic, and testbench-based functional verification.

## Project Details

- **Project Number:** 20
- **Domain:** VLSI
- **Difficulty:** Intermediate
- **Duration:** 4 Weeks
- **Project Type:** Individual Project

## Objectives

- Understand AXI4-Lite communication protocol.
- Design an AXI4-Lite Slave Interface using Verilog HDL.
- Implement read and write data paths.
- Develop testbenches for functional verification.
- Perform simulation and synthesis using Xilinx Vivado.

## Technologies Used

- Verilog HDL
- Xilinx Vivado 2025.2
- RTL Design
- Behavioral Simulation
- FPGA Design Tools
